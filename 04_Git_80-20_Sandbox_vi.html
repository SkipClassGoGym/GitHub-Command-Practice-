Một ngày làm việc với Git

Vòng lặp GitHub Flow: nhánh ngắn, pull request, merge, dọn dẹp. Nhiệm vụ 13 trong sandbox đi qua đúng vòng này.

git checkout main && git pull          # bắt đầu từ main mới nhất
git checkout -b feature/sales-chart      # mỗi việc một nhánh
# ...sửa code...
git status
git add .
git commit -m "Add monthly sales chart"
git push -u origin feature/sales-chart   # rồi mở Pull Request trên GitHub
# review xong, merge PR trên GitHub, rồi:
git checkout main && git pull
git branch -d feature/sales-chart        # xóa nhánh đã merge

10 quy tắc giúp bạn tránh rắc rối

  1. Đi làm thì không commit thẳng lên main.Main luôn phải ở trạng thái deploy được. Tạo nhánh, mở pull request, review, rồi merge.
  2. Chạy git status trước khi add, commit, chuyển nhánh.Phần lớn lỗi là do một file nằm sai ô.
  3. Clone một lần, sau đó pull.Clone lại sẽ bỏ mất lịch sử và các nhánh local của bạn.
  4. Message phải có ý nghĩa."Add login validation", đừng viết "update" hay "first commit". Tiếng Anh, ngắn, cụ thể.
  5. Viết .gitignore trước lần git add . đầu tiên.Loại .env, API key, *.log, __pycache__/, file dữ liệu lớn. Bí mật đã commit thì nằm mãi trong lịch sử.
  6. git push không đẩy tag.Dùng git push origin v1.0 hoặc git push --tags.
  7. Fetch để xem, pull để áp dụng.git fetch chỉ cập nhật origin/main; git pull còn merge vào nhánh của bạn.
  8. Push bị từ chối là chuyện bình thường.Có người push trước: git pull, sửa conflict nếu có, rồi push lại. Đừng --force lên nhánh dùng chung.
  9. Conflict chỉ là hai người sửa cùng dòng.Chọn một bên hoặc cả hai, xóa các dấu <<<<<<< ======= >>>>>>>, rồi add và commit.
  10. Không viết lại lịch sử đã chia sẻ.Không amend, rebase hay reset commit mà người khác đã pull. Xóa nhánh sau khi PR đã merge.

Tạm thời có thể bỏ qua

Nhánh release và hotfix của GitFlow, rebase tương tác (rebase -i), Git hooks và pre-commit, .gitattributes, nhánh orphan, credential helper, và sự khác nhau giữa --soft/--mixed của reset. Học từng thứ khi team hoặc dự án cần; sách Pro Git (git-scm.com/book) có đủ cả.
