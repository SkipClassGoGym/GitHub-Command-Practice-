One working day with Git

The GitHub Flow loop: short branch, pull request, merge, clean up. Mission 13 in the sandbox walks through it.

git checkout main && git pull          # start from the latest main
git checkout -b feature/sales-chart      # one branch per task
# ...edit files...
git status
git add .
git commit -m "Add monthly sales chart"
git push -u origin feature/sales-chart   # then open a Pull Request on GitHub
# after review, merge the PR on GitHub, then:
git checkout main && git pull
git branch -d feature/sales-chart        # delete the merged branch

Ten rules that keep you out of trouble

  1. Never commit straight to main at work.Main must always be deployable. Branch, pull request, review, merge.
  2. Run git status before add, commit and switch.Most mistakes are a file in the wrong box.
  3. Clone once, then pull.Cloning again throws away your local history and branches.
  4. Write messages that explain."Add login validation", not "update" or "first commit". English, short, specific.
  5. Write .gitignore before the first git add .Keep out .env, API keys, *.log, __pycache__/, data dumps. Once committed, a secret stays in history.
  6. git push does not send tags.Use git push origin v1.0 or git push --tags.
  7. Fetch looks, pull applies.git fetch only updates origin/main; git pull also merges it into your branch.
  8. A rejected push is normal.Someone pushed first: git pull, fix any conflict, push again. Never --force a shared branch.
  9. A conflict is just two edits to the same lines.Choose one side or both, delete the <<<<<<< ======= >>>>>>> markers, then add and commit.
  10. Don't rewrite shared history.No amend, rebase or reset on commits others pulled. Delete branches once their PR is merged.

Safe to skip for now

GitFlow release and hotfix branches, interactive rebase (rebase -i), Git hooks and pre-commit, .gitattributes, orphan branches, credential helpers, and the --soft/--mixed nuances of reset. Learn each one when a team or project asks for it; the Pro Git book (git-scm.com/book) covers them all.
